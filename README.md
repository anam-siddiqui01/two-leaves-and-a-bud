# Two Leaves and a Bud 🍵

A frontend website recreation inspired by the official Two Leaves and a Bud tea website, developed as part of **Sheryians Coding School – Cohort 3, Assignment 6**.

## 🌿 Overview

This project recreates a modern tea e-commerce landing page with a focus on clean layouts, product presentation, typography, and visually engaging sections.

## ✨ Features

- Modern navigation bar and hero section
- Tea product cards and collections
- Product categories and discovery section
- Brand story and customer testimonials
- Featured tea latte section
- Tea journal and blog cards
- Newsletter subscription section
- Detailed footer with multiple navigation links
- Responsive layouts for different screen sizes

## 🛠️ Tech Stack

- HTML5
- CSS3
- Remix Icons
- Google Fonts
- Flexbox and CSS Media Queries

## 🎯 Learning Outcomes

- Improved HTML page structuring
- CSS Flexbox and layout management
- Responsive web design
- Custom typography and font integration
- Hover effects and transitions
- Building multi-section landing pages
